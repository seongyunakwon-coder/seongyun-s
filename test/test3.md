# 항목 이름을 쓰지 않고 정리를 시키는 방법

## 1. 이미 있는 섹션을 가리키기 (가장 간단)
```
summary.md를 읽고 readme.md의 '아카이브에서 본 것' 섹션과 같은 형식으로 정리해서 test/test3.md에 저장해줘.
```
- readme에서 그 섹션을 찾아 같은 항목·같은 틀로 다시 쓴다.

## 2. 파일을 예시로 주기
```
test.md처럼 summary.md를 정리해줘.
```
- test.md의 제목과 항목 구성을 그대로 따른다.

## 3. 목적만 말하기
```
summary.md를 보고 내일 팀 회의에서 쓸 수 있게 짧게 정리해줘.
```
- 항목을 Claude가 정하므로 구성이 달라질 수 있다.

## 정리
- 매번 같은 형식을 원하면 1번이나 2번이 확실하다.
- 자주 쓸 거면 CLAUDE.md에 "'아카이브 정리해줘' = test.md 형식" 규칙을 한 줄 넣어 두면 짧게 시킬 수 있다.
