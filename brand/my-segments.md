# 타겟 고객 분류 — 충전 방식 (권성윤 안, 11/19)

> 「쉬었茶 가랑께」 — 무등산 춘설차 K-웰니스 기획전
> 프로그램 출처: `chunseol-program-master.md`

## 왜 나이가 아니라 '충전 방식'인가

- 쉼은 나이와 상관없이 지친 사람이라면 누구나 원한다. 20대도 조용히 쉬고 싶고, 60대도 춤추고 싶을 수 있다.
- 우리 프로그램은 이미 "어떻게 충전하느냐"로 나뉘어 있다. 기획서의 충전 순서 **비우기 → 받기 → 채우기**와도 이어진다.
- 그래서 나이 대신 **스트레스를 푸는 방식**으로 타겟을 나눈다.

## 타겟 3가지

### 1. 놀면서 푸는 사람 (발산형)

| 항목 | 내용 |
|---|---|
| 어떤 사람 | 스트레스를 몸으로 털어낸다. 춤추고 뛰고 나면 개운해진다 |
| 원하는 것 | 술 없이도 신나게 노는 경험, 같이 즐기는 사람들 |
| 맞는 프로그램 | 해 질 녘 사일런트 디스코 + 춘설 목테일, 모닝 레이브, 모닝 트레일 러닝 + 명상 |
| 대표 상품 | 1박 2일 「산에서 놀고, 도심에서 잔다」 |
| 한 문장 | "광주 산자락에서 헤드폰 끼고 춤추다가, 마지막엔 헤드폰 벗고 산 소리 들었어." |

### 2. 조용히 내려놓는 사람 (비움형)

| 항목 | 내용 |
|---|---|
| 어떤 사람 | 사람과 소음, 직함에서 벗어나 아무것도 안 하고 싶다 |
| 원하는 것 | 아무도 나를 묻지 않는 시간, 몸이 풀리는 느낌 |
| 맞는 프로그램 | 무등 찻자리(이름·직업·나이를 묻지 않는 산 위의 한 잔), 춘설 족욕, 국악 사운드 배스 |
| 대표 상품 | 무등 찻자리 + 족욕 |
| 한 문장 | "산 중턱에서 차를 내려주는데, 거기선 아무도 뭐 하는 사람인지 안 물어봐." |

### 3. 직접 해 보고 남기는 사람 (몰입형)

| 항목 | 내용 |
|---|---|
| 어떤 사람 | 손으로 만들고, 배우고, 가져가는 데서 만족을 느낀다 |
| 원하는 것 | 나만의 결과물, 다시 올 이유 |
| 맞는 프로그램 | 햇차 오픈런(채엽·제다 원정대), 다도익선(의재미술관 프로그램 + 차), 찻자리의 '한 장 그리기', 차나무 한 그루 입양, 첫눈 찻자리 |
| 대표 상품 | 햇차 오픈런, 차나무 입양 |
| 한 문장 | "무등산 차밭에서 직접 딴 찻잎을 덖어서 내 차로 가져왔어." |

## 처음 생각한 연령별 타겟과의 관계

| 처음 안 (연령별) | 충전 방식에서는 |
|---|---|
| 파티를 좋아하는 2030 (모닝 레이브) | 발산형 |
| 다도를 즐기는 5060 | 몰입형 또는 비움형 |
| 연말 선물로 티 세트를 사는 30~50대 | 몰입형의 '가져가는 것' (상품 고객) |

## 활용 아이디어

- 기획전 사이트에 **"당신은 어떤 충전형?"** 테스트를 넣고, 결과에 맞는 프로그램을 추천한다.
- 프로그램 소개와 홍보 문구를 세 유형별로 다르게 쓴다.
