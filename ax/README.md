# AX 실습 3가지

반복되거나 귀찮은 일상 습관 세 가지를 Claude와 함께 작은 도구로 만들었습니다.

| # | 폴더 | 무엇을 하나 | 온라인 버전 |
|---|---|---|---|
| 1 | [01-youtube-player](01-youtube-player/) | 좋아하는 아이돌·인플루언서 영상을 내 취향 가중치에 따라 자동으로 골라 연속 재생 | [취향 이어보기 (폰용)](https://claude.ai/artifact/VBtN9P3dfaL7CMRGmFBiyj) |
| 2 | [02-picture-books](02-picture-books/) | 긴 소설을 그림책으로 줄여 흥미를 붙이고, 1주·2주·한 달 완독 플랜으로 실제 완독까지 | [그림책 서재](https://claude.ai/artifact/WG9vMnh5TDzGf58jxhbwmd) |
| 3 | [03-daily-quiz](03-daily-quiz/) | 요일마다 분야가 바뀌는 대학 교양 수준 퀴즈. 먼저 풀고, 해설과 미니 강의로 배우기 | [매일 교양 퀴즈](https://claude.ai/artifact/8HT6r5giNPy2kCJ1ATW8QZ) |

온라인 버전 링크는 비공개 아티팩트라 공유 설정 전에는 본인만 열 수 있습니다. 폰에서는 Claude 앱이나 claude.ai에 같은 계정으로 로그인한 브라우저에서 열면 됩니다.

1번의 PC용 `index.html`은 화면 안에서 영상을 바로 재생하지만 로컬 서버가 필요합니다. 아티팩트에서는 유튜브를 페이지 안에 넣을 수 없어서, 폰용 `mobile.html`은 고른 영상 최대 50개를 유튜브 재생목록으로 만들어 유튜브 앱·브라우저에서 이어 틉니다. 사람 목록과 프로필은 두 페이지가 `data.js`를 함께 씁니다.

## 로컬에서 실행

유튜브 영상은 `file://`로 열면 재생되지 않아서 작은 로컬 서버를 씁니다.

```powershell
powershell -ExecutionPolicy Bypass -File ax\serve.ps1
```

그다음 브라우저에서 엽니다.

- http://localhost:8791/01-youtube-player/
- http://localhost:8791/02-picture-books/
- http://localhost:8791/03-daily-quiz/

## 1. 취향 자동재생 (01-youtube-player)

- 카리나(aespa), 안나(MEOVV), 문지혜, Karen Napoly, Candela Gallo 영상 약 115개 (2026-11-26 유튜브 검색 기준)
- 위 5명을 바탕으로 고른 추천 5명: 윈터(aespa), 장원영(IVE), 카즈하(LE SSERAFIM), Lisa Napoly, Sanne Vloet. 영상 약 130개, "추천" 표시와 추천 이유가 붙고 처음엔 가중치 0.6으로 덜 자주 나옴
- 재생 중인 사람의 기본 프로필 카드(본명, 활동, 국적, 생년월일·만 나이, 출처). 확인된 공개 정보만 적고, 확인 못 한 항목은 "공개 정보 없음"으로 표시
- 사람별 가중치로 랜덤 선택, 최근 본 40개는 다시 안 나옴
- 👍 누르면 그 사람이 더 자주, 👎 누르면 그 영상은 다시 안 나옴
- 처음엔 음소거로 자동재생, "소리 켜기"를 한 번 누르면 이후 계속 소리 켜짐
- 취향 기록은 브라우저 localStorage에 저장

## 2. 그림책 서재 (02-picture-books)

- **그리스인 조르바** (니코스 카잔차키스): 표지 + 12장면
- **카라마조프가의 형제들** (도스토옙스키): 표지 + 12장면
- 어린이 / 어른 읽기 모드 (어른 모드는 장면의 의미를 더 깊게 설명)
- 마지막 장: 등장인물 카드, 토론 질문, 원작 읽는 요령
- 완독 플랜
  - 그리스인 조르바: 열린책들 세계문학 21, 이윤기 옮김, 482쪽
  - 카라마조프가의 형제들: 민음사 세계문학전집, 김연경 옮김, 1권 593 / 2권 479 / 3권 581쪽 (알라딘 상품 정보 기준)
  - 1주 / 2주 / 한 달 중 선택, 이미 읽은 곳부터 나누기, 밀리면 오늘부터 다시 나누기
  - 체크할 때마다 진행률에 맞는 응원 메시지, 완독하면 축하 화면
- 그림은 SVG로 직접 그린 일러스트, 글은 원작 줄거리를 새로 쓴 것 (번역문 인용 없음)

## 3. 매일 교양 퀴즈 (03-daily-quiz)

| 일 | 월 | 화 | 수 | 목 | 금 | 토 |
|---|---|---|---|---|---|---|
| 논리 스프린트 | 과학 | 정치·사회 | 언어·철학 | 예술·역사 | 경제 | 직관 훈련 |

- 요일마다 하위 주제가 주 단위로 돌아가며 범위를 넓힘 (홈에서 직접 골라도 됨)
  - 과학: 기초과학 → AI·디지털 → 건강·의학 → 기후·환경
  - 정치·사회: + 법과 권리 / 언어·철학: + 윤리, 세계 종교 / 예술·역사: + 세계 지리·문화
  - 경제: + 개인 재무 / 직관 훈련: + 통계·데이터 읽기, 심리학 / 논리: + 미디어 리터러시
  - 새 하위 주제 문제는 Claude가 출제 (기본 문제는 기초 주제만), 내 기록에서 하위 주제별 정답률을 봄
- 5문항, 답과 함께 확신도(확신 / 반반 / 찍음)를 고름
- 결과를 "착각(확신했는데 틀림) / 운 / 빈칸 / 아는 것"으로 나눠 보여 줌
- 문항마다 해설 + "더 알아보기" 미니 강의, 직관·논리 날은 60초 타이머와 단계별 논리 전개
- 서술형 한 문제를 Claude가 채점
- 게임 요소: 정답마다 경험치(확신하고 맞히면 +5, 연속 정답 콤보 보너스, 직관·논리 빨리 맞히면 +5, 만점·오늘 첫 세트 보너스), 새내기부터 노벨상 후보까지 레벨, 연속 학습 🔥, 배지 10종. 맞히면 작은 폭죽, 틀리면 시험지가 흔들리고, 레벨이 오르면 축하 화면이 뜸. 모두 풀이 기록에서 계산해서 예전 기록에도 경험치가 쌓임
- claude.ai에서 열면 Claude가 매일 새 문제를 출제 (최근 틀린 주제 반영), 로컬에서는 분야별 기본 문제 35개로 동작
- "이야깃거리" 탭: 친구·동료와 나눌 만한 최근 이슈 5~6개(인사이트 + 웃긴 소식)를 요약, 왜 볼 만한지, 대화 질문, 출처 링크와 함께 보여 줌. 지난 7일 치를 넘겨 볼 수 있고 "단톡방용으로 복사" 버튼이 있음
- 이야깃거리는 Claude 데스크톱 앱의 예약 작업 `daily-quiz-issues`가 매일 아침 7시 30분쯤 뉴스를 검색해 아티팩트 데이터(`issues/<날짜>`)에 저장 (앱이 꺼져 있으면 다음에 켤 때 실행)
